    Announce display permission errors; forward SIGINT as Ctrl+C.

    Surface /dev/fb* and DRM open failures on the real console as well as
    the log, and treat terminal Ctrl+C as key events for the focused client
    instead of killing the server (SIGTERM/exit shortcut still quit).

+	if (!fmt)
