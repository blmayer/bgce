    Improve BGCE_DEBUG logs: op names, workers, positions.

    Log DRAW/MOVE/PAN with world and screen positions, name jobs instead of
    numeric ops, and record which FCFS worker took each MOVE task. Rate-limit
    CURSOR lines (1/32) so mouse traffic does not hide client draws; fflush
    debug output for the log pipe.
