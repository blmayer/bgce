    Trap SIGINT only; detach shortcut children from process group.

    Stop synthesizing Ctrl+C on SIGINT — that double-delivered with
    /dev/input. Swallow the signal so the server stays up; clients get
    interrupt only as keyboard events to focus. setsid() shortcut forks
    so terminal SIGINT does not kill every launched app.
