    Avoid painting the software cursor during compositor blits.

    Set fb_writing while draw/pan/move touch the framebuffer so the input
    thread only updates the hotspot and marks dirty, then re-presents after
    the blit. Prevents half-frame underlay restores that freeze window
    content under the pointer.
