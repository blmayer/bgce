    Fix compositor mouse freezes; keep orchestrator from stealing work.

    Drop jobs when the queue is full so input never blocks, present the cursor
    after each paint job, and update the pointer before submitting drag paint.
    Orchestrator only enqueues FCFS tasks and waits — workers alone run them.
