    Always restore VT keyboard mode on exit so the tty is not frozen.

    Leaving K_OFF when KDGKBMODE failed at startup meant quit only set
    KD_TEXT and the console stayed keyboard-dead. Track K_OFF, fall back
    to K_XLATE, and re-open /dev/tty if needed during release.
