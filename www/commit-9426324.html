    Restore bgce_get_buffer by-value ABI so existing apps work.

    Changing the request to a pointer made every prebuilt client treat the
    packed BufferRequest as an address and crash in get_buffer, so nothing
    appeared on screen. Revert the pointer API and server-side zoom size
    scaling; keep the faster compositor blit paths.
